## Project overview

The website includes content for:
- KTS Academy (JEE, NEET, 11th, 12th)
- Score High (banking exams, online practice papers)
- KTS IT Solutions (CBT, BPO, career counselling, IT recruitment)
- KTS Marketing (digital campaigning, brand endorsement, content strategy)
